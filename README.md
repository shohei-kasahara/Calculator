Create a new Android Studio project named Calculator which has the following features:
• It has two input texts (numbers)
• It has four buttons showing ‘Addition’, ‘Subtraction’, ‘Multiplication’ and ‘Division’
• It has one output text view (text)
• Based on the user input and button click, do the calculation and show result on the output text view.

Handle special cases so that the app does not crash when:
• User clicks on a button without entering inputs for both fields.
• User tries to create a case ‘divided by 0’.
